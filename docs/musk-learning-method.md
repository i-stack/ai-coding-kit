# 马斯克学习相关公开言论：原话校验与可执行主干

本文不是马斯克发布的教程。原稿是后人把他公开说过的话拼成五步「学习法」。本文只做两件事：

1. 用公开言论校验原稿：不是他说的删除；他说过但原稿没收的补上。
2. 以修正后的可执行结论为主干，把每一步拆开。拆开部分是操作展开，不冒充原话。

口径：只认马斯克自己的公开口述 / 访谈。同事转述、传记侧写、内容农场的方法论命名一律不进入「原话层」。中文场合（清华 2015、G20 2022）为转写，不是英文逐字稿。

### 1.3 他公开说过、原稿没收的

1. **类比是默认**；第一性原理是做新东西时的例外（TED2013）。
2. **主动要负反馈，尤其向朋友要**（TED2013；G20 2022 再讲过）。
3. **永远假设自己某种程度上是错的，目标是少错一点**（2017 世界政府峰会；G20 2022）。
4. **物理是规律，其他都是建议**（G20 2022 等）。
5. **先问题、后工具**：先问为什么学、要解决什么，再学工具；否则脑子会忘（G20 2022）。
6. **读书 + 交谈 + 实验**；实验是因为书里未必正确（清华 2015-10-22）。
7. **看书比听课快**；信息都在那儿（清华 2015）。
8. **物理 101 / 物理学思维框架最有用**（清华 2015）。
9. **可重复火箭例子**（清华 2015）：不要因航天飞机变贵就否定重复使用；推进剂相对箭体很便宜；原材料只占总价百分之几，关键是如何把材料变成想要的形状。
10. **电池例子**（2012 Kevin Rose，广泛转述）：不要接受「电池组一直很贵所以永远很贵」；拆成镍 / 钴 / 铝等，去交易所看原料价，再往上推。数字是当时举例，不是今日行情。
11. 被问如何跨那么多领域：**没有好答案，工作量很大**（TED2013）。
12. **The Algorithm**（经营 / 生产，不是学习）：质疑每条需求、能删就删、再简化、再加速、最后才自动化。完整五步清单以 Isaacson 2023 引述为主；他本人公开讲过「先让需求不那么蠢」、聪明人给的需求最危险。

### 1.4 校验后的原话层

可引用，不要再焊成教程名：

- 知识像语义树：先主干和大枝，再叶子。
- 日常靠类比；做新东西才从基本事实往上推。
- 读很多书，和很多人交流，还要做实验（书会错）。
- 先搞清为什么学、要解决什么问题，再碰工具。
- 假设自己有错，要少错；向朋友要难听的反馈。
- 物理是规律，其余是建议。
- 造产品时：先质疑需求，先删，最后才自动化。

## 2. 可执行主干

下面五步是操作手册，不是马斯克发布的教程。每步先给对应原话，再给展开。展开部分若当原话用，整份作废。

总顺序：

**目标先定 → 主干先立 → 习惯用类比先跑起来 → 新问题才拆到事实往上推 → 做出来挨打，用负反馈改模型。**

造产品时另跑 Algorithm，不要插进这五步中间冒充学习法。

### 第 1 步：目标先定

对应原话（G20 2022）：学东西先建立相关性——你为什么要学这个？脑子一直在忘。教育常把工具倒过来教；应先是想做什么、要解决什么问题，再在解题时需要哪种工具。

做什么：

1. 用一句话写要做成的东西（可演示、可失败），不要写「学 iOS / 学火箭」。
2. 再写何为失败（两周后仍讲不清主干、或做不出最小可测物）。
3. 列这个问题会用到的工具，当工具清单，不当学习大纲。
4. 清单外的书、课、视频默认不看。

完成标准：外人能听懂你在解决什么；你能指出这门课 / 这本书跟目标哪一条有关。

翻车信号：先买课、先刷语法、先收藏 30 个教程，还说不清两周后要交出什么。

### 第 2 步：主干先立

对应原话（AMA 2015）：把知识看成语义树；先理解基本原理（trunk and big branches），再进入细节（leaves），否则细节没有挂靠处。清华 2015：物理基础理论 / 物理 101 最有用。

做什么：

1. 只问 5–10 个主干问题，标准是：这个问题讲不清，后面所有细节都无处可挂。
2. 每个主干用自己的话讲 3 分钟，不许念定义。讲完问：如果删掉这个，整棵树会不会倒。
3. 主干未稳前，禁止：背 API、背手册页、刷题库、记边角案例。
4. 遇到细节先问：它挂在哪根枝上？挂不上就回到第 2 步，不新开叶子。

完成标准：能画一页树：树干、3–6 根主枝、暂无叶子；能给别人讲，对方能复述结构。

翻车信号：笔记很厚，但问「这个领域到底在解决什么物理 / 约束问题」时卡壳。

### 第 3 步：习惯用类比先跑起来

对应原话（TED2013）：生活大部分时间靠类比，本质是复制别人再小改；必须这样做，否则过不完一天。只有做新东西才上物理方法。

做什么：

1. 把当前任务标成两类：
   - 已有解（别人做过、有惯例）→ 走类比。
   - 还没有你要的那种解 → 留给第 4 步。
2. 已有解：找一个能跑的最小模仿对象，先做出 80 分能用的，再小改。
3. 明确你在复制什么、改了什么；不要把「我跟过教程」说成「我懂本质」。
4. 类比只用来让系统转起来，不用来证明「只能这样」。

完成标准：有一个能跑的最小版本；你能指出哪些是抄来的惯例。

翻车信号：日常任务也要「从原子重新推导」，或反过来把行业惯例当成自然律。

### 第 4 步：新问题才拆到事实往上推

对应原话：TED2013「做新东西才用物理方法」；清华 2015 可重复火箭；G20「不违反物理就有可能，谁的意见都无所谓」。

做什么（只在第 3 步的惯例挡路时启动）：

1. 写下正在挡路的那句惯例（「一向如此」「专家说必须」「电池永远贵」「重复使用更贵」）。
2. 拆成三类，不许混：
   - 物理 / 可测事实（守恒、材料成本、质量、时间、能量）
   - 人定规则（法规、审核、部门流程）
   - 习惯（竞品做法、历史价格、口碑）
3. 只把第一类当基点往上推：若基点为真，最小可行解是什么。
4. 人定规则当约束，不当真理；习惯可以删。
5. 用他用过的问法检查：
   - 火箭：材料堆在房间里值多少，其余是不是「变成形状」的浪费？
   - 电池：市场价是不是被当成了物理事实？原料价是多少？
   - 通用：这条限制是自然律，还是建议？

完成标准：有一张「惯例 / 事实 / 新推论」三列纸；新推论能指出可测的下一刀。

翻车信号：把「我想颠覆」当成第一性原理；或把平台契约（API、审核条款）当成能从物理推出来的东西。

### 第 5 步：做出来挨打，用负反馈改模型

对应原话：清华 2015——要实验，书里未必正确。TED2013——认真对待负反馈，尤其向朋友要。G20——假设自己有错，要少错；寻找批评性反馈。物理会惩罚：火箭会炸。

做什么：

1. 把第 3 / 4 步的结论变成 48–72 小时内能失败的实验（能炸、能测、能丢脸），不要再开一章笔记。
2. 事先写：若我是对的，会看到什么；若我是错的，会看到什么。
3. 主动找 1–2 个懂的人要难听的；不要等公开爆炸才学。
4. 失败只改模型里被打到的那一条，不改自尊、不把整棵树砍掉。
5. 每天的目标不是「证明我对」，是「今天比昨天少错一点」。

完成标准：有一次真实反馈（测试、评审、用户、物理现象）；笔记里能看到「哪条信念被改了」。

翻车信号：只学不做；或做了但把失败解释成「执行差、别人不懂」，模型一字不改。

### 另轨：造产品时的 Algorithm

不要并入上面五步。

公开大意：需求往往是蠢的，聪明人给的更危险；能删就删；不要先优化不该存在的东西；最后才自动化。

顺序锁死：

1. 质疑需求（问到具体人）
2. 删除
3. 简化
4. 加速
5. 最后自动化

这是把已经在跑的系统变瘦，不是进入陌生领域的学习顺序。

## 4. 一句话结论

原稿不是一整套学习法。能留的原话是：语义树的学习顺序、做新问题时从可核验事实往上推、读书 + 交谈 + 实验、先问题后工具、默认自己有错并要负反馈。日常必须靠类比。「拒绝类比、背手册、榨取专家、靠这套跨领域」不是他的公开原话。
