# project-decision-evaluation Agent 调用指南

## 一句话描述

对商业项目、产品方向和内部创新进行门禁、实验、评分、排序和持续治理，输出唯一决策状态。

## 何时调用

- 立项、Go/No-Go、商业可行性或产品机会评估。
- MVP 实验、候选项目排序、停止条件或项目复盘。
- 判断项目应立即启动、有条件启动、先实验、暂缓、转型或终止。

## 关键行为

1. 完整阅读 `SKILL.md` 和 `references/project_decision_framework.md`。
2. 硬门禁先于分数，不用高分覆盖合规、风险、资金或执行缺口。
3. 不虚构市场、成本、概率、竞争和合规数据；信息不足时标记待验证。
4. 输出唯一决策状态、证据与置信度、最小实证、责任人和下一复盘点。

## 不调用的情况

- 代码审查、PR Review 或技术架构体检。
- 普通开发任务估时、需求拆分或实施计划锁定。
- ROI、机会成本等单一概念解释。
