# project-decision-evaluation 范围外

本 Skill 负责判断商业项目、产品方向或内部创新是否值得启动、验证、暂缓、转型或终止。

## 不处理的内容

- **代码和 PR 审查**：由对应工程 Skill 或 `auto-code-review` 处理。
- **技术架构健康度**：由对应平台工程 Skill 处理。
- **需求盘问与实施计划**：由 `plan-grill` 处理。
- **自动执行决策**：评估不授权立项、投资、采购、发布、终止或对外联系。
- **代替专业意见**：法律、监管、医疗、重大资金和不可逆结论需要可问责的专业审查。

## 与 plan-grill 的边界

- `project-decision-evaluation` 回答“这个项目是否值得做”。
- `plan-grill` 回答“已选定的软件需求具体怎么做”。
- 项目决策未通过时，不因本 Skill 自动进入代码实现。
