# Learning Loop

## 强制入口

命中本 skill 时，**必须先完整阅读** [references/learning_loop.md](references/learning_loop.md) 并按其中条款执行。

- 不得以 preamble、规则摘要或其它二次摘要代替该文件全文。
- 规则 ID 真值索引见 [references/rule_index.md](references/rule_index.md)。
- 涉及方法来源、原话归属或证据等级时，必须读取 [references/provenance.md](references/provenance.md)。
- 问题检验、真值接地与需求盘问分别由 `problem-analysis`、`cognitive-reasoning`、`plan-grill` 承载，本 skill 只委托，不内联第二套规则。

## 八条核心规则

- [LL-001] **触发门控**：仅主动触发（`@learning-loop` /「按五步来」/「用学习闭环」），不自动加载、不做发送时自动拦截。
- [LL-002] **目标先定**：用一句话写明可演示、可失败的交付物，并定义何为失败；材料按与目标的相关性筛选。
- [LL-003] **主干先立**：先建立少量主干约束并复述其逻辑，细节挂到主枝上；挂不上的细节暂缓。
- [LL-004] **类比优先**：任务先分类。已有成熟解法时复用最小可运行参考建立基线，并标明复用与微调的边界；无有效解法或成本过高时转 LL-005。
- [LL-005] **三类约束深拆**：仅在惯例阻碍目标时，把约束分为客观事实 / 人定规则 / 历史习惯，从不可违反的事实与当前有效边界共同推导；删除历史习惯前查明其承载的安全、兼容、可靠性功能并准备替代机制。
- [LL-006] **闭环校准**：实验前写清「假设成立会看到什么、错误会出现什么偏差」，输出可失败的验证清单，主动请求严苛反馈；只修正被证伪的具体节点。
- [LL-007] **授权与执行边界**：执行范围服从用户原请求；纯分析请求不修改状态，明确要求实现时可使用必要工具完成并验证。`cross-model-review` / `auto-code-review` 仍需单独显式授权；不新增机械输出块。
- [LL-008] **证据口径**：五步是作者综合的启发式，不是当事人原话，也不是经对照实验验证的通用定律；带 C 级标注的转写不得作为确定原话引用。

## 入口语义

- **主动触发**：用户输入「按五步来」「用学习闭环」或 `@learning-loop`，并同时给出待解决的具体任务。
- **不触发**：普通对话、事实查询、翻译、纯机械改动、代码生成等未显式请求五步推进的输入。
- 触发后五步作为内部推进顺序；用户显式要求查看过程时，输出一份五步清单，复用既有主答与四段式结构。

| `plan-grill` | 需求盘问与 PLAN.md 锁定（LL-002 需要时委托） |

| `cross-model-review` / `auto-code-review` | 用户显式授权后的对抗审查；本 skill 不发起 |
