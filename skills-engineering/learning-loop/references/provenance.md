# Learning Loop 来源与证据口径

本表提供运行时判断方法归属与引用强度所需的最低证据集。五步流程是作者综合的启发式，不是马斯克本人提出的完整方法，也不是经对照实验验证的通用学习定律。

## 证据等级

- **A 级——一手可核验**：本人账号、主办方视频或可定位的访谈逐字稿。
- **B 级——可靠二手记录**：传记或可追溯的完整转写，但不是本人发布的原始材料。
- **C 级——待核实转写**：缺少可核对的官方视频、逐字稿或时间戳，只作待核实线索，不作确定原话引用。

## 引用规则

- A 级内容仍应优先使用概括性转述；需要逐字引用时回到链接核对原文与上下文。
- B 级内容标注为传记或二手记录，不升级为本人公开原话。
- C 级内容只作待核实线索；没有新的一手证据时不得升级等级。
- 未列入本表的归属与措辞不得凭记忆补全，须查证后再陈述。
