# learning-loop 范围外

本 skill 承载五步推进顺序，并在用户原请求的授权范围内完成分析、实现与验证；不重复实现问题检验、真值接地与需求盘问。

## 不处理的内容

- **超出原请求的外部动作**：纯分析请求不跑测试 / 构建、不改代码；实现请求可执行完成交付所必需的本地修改与验证，但不据此扩大到部署、发布或其它外部状态变更。
- **跨模型审查**：发起 `cross-model-review` / `auto-code-review` 需要用户显式授权，本 skill 不触发、不代为选择 reviewer。
- **问题检验与真值接地**：逻辑检验、事实 / 推理分流、论证质量由 `problem-analysis` 与 `cognitive-reasoning` 负责。
- **需求盘问与计划锁定**：由 `plan-grill` 负责，本 skill 不产出 PLAN.md、不维护第二套盘问规则。
- **扩展来源考据**：运行时所需的最低来源分级与可核验链接见 `references/provenance.md`；超出该表的考据不由本 skill 推断。
- **机械输出块**：不新增独立 anchor 块，避免与 `.agents/composition.md` 的 L0–L5 块发射顺序冲突。

## 触发门控

仅在用户显式请求五步推进时触发。普通对话、事实查询、翻译、闲聊、纯机械改动等输入跳过。
