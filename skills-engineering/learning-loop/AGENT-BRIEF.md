# learning-loop Agent 调用指南

## 一句话描述

用户显式请求按五步推进时，先定可失败交付物、立主干约束、按任务分类复用成熟解法、仅在惯例卡住时做三类约束深拆，最后完成与用户原请求一致的实现或分析，并用观察指标与可失败验证清单闭环。

## 何时调用

- **主动触发（LL-001）**：用户输入「按五步来」「用学习闭环」或 `@learning-loop`，并给出具体任务。
- **跳过**：普通对话、事实查询、翻译、闲聊、纯机械改动、代码生成等未显式请求五步推进的输入；未触发时本 skill 不参与执行。

## 关键行为

1. 阅读 `SKILL.md` + `references/learning_loop.md` 全文。
2. 目标先定（LL-002）：写一句话交付物与失败定义；相关性不足的材料暂缓。
3. 主干先立（LL-003）：列少量主干约束，细节挂主枝，挂不上则暂缓。
4. 类比优先（LL-004）：任务分类；有成熟解法则给出最小可运行基线与复用 / 微调边界，无解则转第 5 步。
5. 三类约束深拆（LL-005）：把惯例分为客观事实 / 人定规则 / 历史习惯，写三列分析并说明未采纳惯例后的功能覆盖。
6. 闭环校准（LL-006）：写观察指标、可失败验证清单与主动求反馈对象；只标记被证伪的节点。
7. 授权与执行边界（LL-007）：纯分析请求不修改状态；明确要求实现时使用必要工具完成并验证；跨模型审查仍需单独授权；不新增机械块。
8. 证据口径（LL-008）：五步是启发式而非原话或定律；C 级转写不作确定原话引用。

## 不调用的情况

- 用户未显式请求五步推进的普通输入。
- 仅要求发起跨模型审查但未显式授权对应工作流的输入。
