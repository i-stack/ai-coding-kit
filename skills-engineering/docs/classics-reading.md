# classics-reading 使用文档

## 概述

`classics-reading` 是克制型中国古典文献解读 skill，确保 AI 在解读《道德经》《易经》《阴符经》《庄子》等先秦典籍或古文经典时，把输出锁死在「有出处、可验证、争议显式呈现」的框架内，抑制自由发挥与编造注疏。

## 解读流程（按顺序执行）

1. **版本先行**：声明依据版本（王弼本/河上公本/帛书甲乙本/郭店楚简本），列出关键异文及其义理影响；不确定时写「此处版本有分歧」。
2. **三层分层**：每条解读按「字面义 → 注疏义 → 个人推演」输出；个人引申冠以【推测】标签。
3. **三条禁令**：禁止跨书联想、禁止争议处给唯一答案、禁止编造注家语录。
4. **不确定表达**：「此义学界无定论」「无明确出处」「字义待考」是合法输出。
5. **自证环节**：结束前列出最没把握的三处并说明原因。

## 锚定注本（治本手段）

模型幻觉九成来自从训练记忆召回注疏。若用户提供权威注本原文，先塞入上下文，让解读「对着原文译注」而非「凭记忆发挥」。推荐锚点：朱谦之《老子校释》、陈鼓应《老子注译及评介》、高明《帛书老子校注》、高亨《周易古经今注》《周易大传今注》。
