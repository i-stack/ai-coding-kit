# problem-analysis Agent 调用指南

## 一句话描述

问题前置分析——逻辑检验、第一性原理拆解、充分理解后再回复（PA-001/002/003）。含判断、方案讨论、实现请求或架构取舍时默认加载。

## 何时调用

- **默认**：收到任何含判断的技术问题、方案讨论、实现请求、架构取舍时。不依赖用户说出「第一性原理 / 深层需求 / 问题偏差」。
- **跳过**：纯机械执行（格式化代码、直接翻译）、无判断成分的信息复述。

## 关键行为

1. **[PA-001] 逻辑检验**：收到问题后先审查是否含逻辑错误、矛盾前提、循环假设或虚假二分。若发现须先揭示，不得在错误前提上直接作答。
2. **[PA-002] 第一性原理**：推理/取舍类从底层需求拆解。事实类走查证，不从第一性原理推导。若存在更优解或更深层需求，必须在正式回复前点明。
3. **[PA-003] 理解门控**：三态——清晰则静默；实质偏差则输出「问题分析」块后作答；底层需求与表层请求不一致则先确认真实意图。

## 不调用的情况

- 纯机械执行
- 无判断成分的信息复述
- 纯翻译/格式化任务
