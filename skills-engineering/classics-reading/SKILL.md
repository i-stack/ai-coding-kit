# Classics Reading（克制型经典解读）

## Overview

对先秦典籍与古文经典的解读，最大的风险是模型自由发挥——跨书拉关系、编造注家语录、跳过版本与句读争议。本 skill 用一套硬约束把解读锁死在"有出处、可验证、争议显式呈现"的框架内。

## 何时使用

- 用户要求解读、翻译、赏析某句/某章古文经典（道德经、易经、阴符经、庄子、论语等）。
- 用户问"这句话怎么理解""帮我解释第 X 章"。
- 用户显式要求"克制模式 / 带注本解读"。

## 何时跳过

- 用户只是引用典籍原文作修辞/论证，并未要求解读其义理。
- 讨论现代汉语文本、白话文、外语文本或非先秦典籍，无需版本与注疏约束。
- 纯信息检索（如"某某书作者是谁"），不涉及逐字训诂与义理分层。

## 解读流程（按顺序执行）

1. **版本先行**：先声明依据的版本（如王弼本 / 河上公本 / 帛书甲乙本 / 郭店楚简本），并列出该章关键异文及其对义理的影响。版本谱系见 [references/authoritative-editions.md](references/authoritative-editions.md)。版本不确定时明确写"此处版本有分歧"，不得默认通行本。

2. **三层分层**：每条解读必须按"字面义 → 注疏义 → 个人推演"三段输出，缺一不可。
   - 字面义：逐字训诂，释义须能引《说文解字》《尔雅》或公认字书，否则标注"字义待考"。
   - 注疏义：只引真实注家观点并注明是哪一家（王弼、河上公、程颐、朱熹等）。
   - 个人推演：自己的引申必须冠以【推测】标签。

3. **三条禁令**（违反即回答无效）：
   - 禁止"与庄子/孔子/佛教等一脉相承"式跨书联想，除非某注家原话如此。
   - 禁止在存在句读/义理争议处给出唯一标准答案——必须并列各方，让读者自择。
   - 禁止编造注家语录。无法确认出处的句子，写"无明确出处"，不得杜撰。

4. **不确定表达**：以下说法是合法且被鼓励的——"此义学界无定论""无明确出处""字义待考""此解仅为我个人推演"。

5. **自证环节**：解读结束后，列出回答中最没有把握的三处，并说明为何没把握。

## 锚定注本（治本手段）

模型幻觉九成来自从训练记忆召回注疏。若用户提供了权威注本原文，先将其塞入上下文，让解读"对着原文译注"而非"凭记忆发挥"。推荐锚点：朱谦之《老子校释》、陈鼓应《老子注译及评介》、高明《帛书老子校注》、高亨《周易古经今注》《周易大传今注》。
