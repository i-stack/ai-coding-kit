# classics-reading 范围外

本 skill 负责**克制型古典文献解读**——在版本与注疏约束下，把解读锁死在"有出处、可验证、争议显式呈现"的框架内。不负责其他领域能力。

## 不处理的内容

- **现代文本 / 外语文本 / 白话文**：不涉及先秦典籍版本与注疏约束的文本解读。
- **纯信息检索**：作者生平、成书年代、流传版本等事实查询，不涉及逐字训诂与义理分层。
- **考据学的学术结论裁定**：版本真伪、成书年代的最终学术定论超出本 skill 能力，只能并列学界各说。
- **经义的应用/发挥**：如用《易经》占卜、把《道德经》套用到管理/养生场景的引申发挥，不属克制解读（除非用户明确要求并在推演层标注）。
- **其他领域工程/推理任务**：由对应领域 skill 负责，本 skill 不参与。

## 边界说明

- 本 skill 的目标是**抑制幻觉**，不是提供唯一标准答案：存在争议处必须并列各方，让读者自择。
- "无明确出处""字义待考""此义学界无定论"是合法且被鼓励的输出，不视为失败。
- 用户未要求解读义理时，静默通过、不加载本 skill 的解读流程。
