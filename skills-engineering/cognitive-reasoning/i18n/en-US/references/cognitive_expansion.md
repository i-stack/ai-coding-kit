Three tiers: Tier 0 (gated tail note), Tier 2 (full CAM), Tier 3 (`【深潜】` deepens with mental model + cross-domain analogy + 7-day action). ## Tier 0 gate
Default silent. Append only when BOTH hold: (1) answer has judgment/choice/attribution; (2) can produce ≥1 falsifiable blind spot. If no qualified blind spot, emit nothing.
