# OUT-OF-SCOPE（cognitive-reasoning）

本技能**不**覆盖以下职责（由其它技能承载）：

- 工程交付结构纪律（排障四段式、前置确认、最小修复、残留风险）→ `engineering-discipline`（GR-001~008）
- 问题本身合理性与第一性原理拆解 → `problem-analysis`（PA-001~003）
- 动手前召回历史线索 → `historical-recall`（HR-001~005）
- 文档卫生纪律 → `doc-hygiene`
- 需求盘问/跨模型审查/自动代码审查工作流 → `plan-grill` / `cross-model-review` / `auto-code-review`
- iOS 平台专属工程（并发/布局/网络/性能/迁移）→ `ios-engineer`

本技能仅管认知与论证**质量**，不产出工程实现、不替代宿主技能的输出骨架。
